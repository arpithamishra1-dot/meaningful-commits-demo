\# Meaningful Commits Demo



\## Project Overview

This project demonstrates meaningful commit messages and proper repository structure using Git and GitHub.



\## Folder Structure



\- src/ - Contains application source code.

\- tests/ - Contains testing scripts.

\- docs/ - Contains project documentation.

\- assets/ - Contains images and other resources.



\## Objective

To practice Git commits, repository organization, and version control using GitHub.



\## Tools Used

\- Git

\- GitHub

\- Git Bash

\- Python
